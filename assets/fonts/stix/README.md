# STIX Two fallback fonts

These unmodified fonts are from the official stipub/stixfonts repository, release v2.13b171, under SIL Open Font License 1.1. See OFL.txt for the complete license and copyright notice. SOURCE.json records exact source URLs, Git blob hashes and SHA-256 digests.

STIXTwoMath-Regular provides upright mathematics. STIXTwoText-Italic, BoldItalic and Bold provide the recovered variable/unit/constant/keyword style distinctions. The outlines are independent fallback faces and are not Mathcad UniMath Prime. No proprietary Mathcad fonts are included or required.

Official source: https://github.com/stipub/stixfonts/tree/v2.13b171
