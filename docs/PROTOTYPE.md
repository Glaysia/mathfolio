# Mathcraft 워크시트 프로토타입

빈 종이 위 원하는 위치에서 수식·텍스트를 작성하고, 수식 자체를 편집하며 위치 순서에 따라 계산하는 초기 구현이다. 수식 트리·영역 좌표·텍스트를 같은 문서에 저장한다. Mathcad 전체 동작을 재현한 제품은 아직 아니다.

## 실행과 입력

Windows 실행 파일은 `target/debug/mathcraft.exe`다. 과거 행 기반 실험의 `mathcraft-app.exe`와 구분한다.

```powershell
./scripts/run.ps1
./scripts/run.ps1 -Open 'worksheet.mathcraft'
```

종이에서 클릭한 뒤 바로 입력한다.

1. `a:=2`를 입력하면 변수 정의 영역이 생긴다. `:`가 정의 연산자를 만들므로 `a:2`도 같은 입력이다.
2. Enter로 아래 위치로 이동한 후 `a+3=`를 입력하면 같은 수식에 `5`가 표시된다.
3. `d:=2m`을 정의하고 아래에 `d=cm`을 입력하면 `200 cm`로 표시한다.

`/`는 세로 분수, `^`는 지수, 괄호는 그룹을 만든다. Space로 부분식 선택 범위를 넓히고 Tab으로 입력 자리를 이동한다. 분수·지수 내부에서 다음 연산자를 삽입하는 자세한 규칙은 원본과 대조가 더 필요하다.

상단 Math/Text에서 텍스트 모드를 선택하고 종이를 클릭하면 메모를 작성할 수 있다. 선택한 영역 왼쪽 손잡이로 위치를 옮긴다. 정의를 평가보다 아래로 옮기면 해당 평가의 변수 오류가 표시된다. Ctrl+Z/Y는 영역 이동·수식·텍스트를 포함한 문서 변경을 되돌린다.

Save/Open은 `.mathcraft` v2에 수식 구조·위치·텍스트를 저장하고 다시 연다. 수식 표시를 문자열로 평탄화하거나 편집기 내부 undo 기록을 저장하지 않는다. 미완성 숫자처럼 현재 저장 검증을 통과하지 못하는 수식은 오류를 알리고 저장을 막는다. 저장하지 않은 문서를 닫거나 다른 문서를 열 때 확인한다.

## MCDX와 지원 경계

MCDX 열기는 일부 기본 수식의 구조 편집과 텍스트 표시를 지원한다. 명시 라벨, 괄호, 분수·지수, 정의·평가와 표시 단위를 보존하며, 표현하지 못하는 영역은 편집 불가로 표시한다. 원본 ZIP 바이트도 v2 문서 안에 그대로 남긴다. 미지원 계산 영역이 있으면 문서 전체 계산을 중단하며 이전 캐시를 새 계산처럼 보여주지 않는다.

현재 저장 형식은 `.mathcraft` v2이며 **편집 내용을 MCDX로 내보내기는 미완료**다. v1 행 기반 실험 문서와 형식이 다르다. 원본 MCDX 파일은 변경하지 않는다. 가져오기 원본은 현재 16 MiB로 제한한다.

기본 산술·단위·지역 정의와 2D 커서의 일부를 연결한 단계다. 함수 입력, 일반 행렬·범위·프로그래밍/풀이 블록·CAS, 완전한 커서/클립보드/한글 IME, 인쇄·페이지 설정은 남아 있다. 자동 라벨과 키 전이 일부는 독립 구현 정책이며 원본의 전체 문맥 해석과 같다고 주장하지 않는다.

## 검증

창을 띄우지 않는 egui 테스트에서 클릭→첫 문자→정의→아래 평가, 연속 프레임별 문자 입력, 위치 이동→오류→undo, 단위 입력/변환, 저장→재열기→동일 계산을 확인한다. 실제 새 UI의 데스크톱 조작과 IME 검증은 아직 하지 않았다. 원본 38개 최소 사례 비교의 정확한 범위는 [호환성 검증](CONFORMANCE.md)을 참고한다.
