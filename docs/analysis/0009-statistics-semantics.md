## Independent implementation

`crates/mathcraft-compat/src/statistics.rs` exports `is_builtin(name)` and `call(name,args)`. Parent dispatch first respects labelled user bindings. Supported names: mean, gmean, hmean, median, var, Var, stdev, Stdev, cvar, corr, min, max, sort, reverse, Rank. Mean accepts complex data; var/Var use complex squared magnitude and real output with squared units. Standard deviation has original units. Complex min/max use componentwise extrema, which can produce a value not present in the input. Median requires real data. Geometric/harmonic means require positive real data.

Cvar/corr currently support real same-shaped arrays only. Cvar permits different dimensions between the two arrays and returns their product; corr returns dimensionless values. Conjugation orientation in the native complex covariance kernel remains unestablished, so complex input returns an explicit unsupported error. Neither covar nor an invented covar alias is registered.

Sort/Rank currently require a column vector. Their ordering keys are real parts and imaginary payloads remain attached to sorted elements. Rank is1-based and averages repeated-key positions. Reverse supports matrices and reverses rows, including the native one-row no-op. Numeric arrays with arbitrary per-cell units can reverse without dimensional inference. Other reductions require matching dimensions within each dataset.

## Deliberate policies and gaps

There is a16,384-element budget and finite numeric validation. Ranges are explicitly rejected rather than silently flattened. Empty arguments, malformed shape, mismatched dimensions and undefined constant-array correlation report errors. Exact original error text/codes, nonfinite/missing/string values, symbolic behavior, tolerance options and full packed argument coercion are unverified. Mean sums scaled inputs and gmean uses logarithms for overflow control; these are independent numerical strategies and do not reproduce original rounding order. Rust sorting is stable; original tie order is unspecified by the help, and no exact duplicate-payload parity is claimed. Row-vector sort/Rank, order/ORIGIN, csort/rsort, matrix rank, mode, percentile, complex covariance/correlation, random distributions and signal covar remain outside this module.
