# CLI MCP skill 연동 계획

2026-10-20. Mathcraft 문서를 외부 AI와 자동화 도구가 읽고 수정·계산할 수 있게 하는 후속 계획이다. 현재는 계획만 기록하며, UI 개선 뒤 별도 작업으로 진행한다.

## 공통 구조

GUI·기존 `mathcraft-cli`·MCP 서버가 동일한 Rust 문서 명령 API를 사용한다. 문서·수식 편집과 계산 로직을 공통 계층에 두고, CLI와 MCP는 입력 검증과 결과 전달을 담당한다.

현재 CLI의 계산·문서 실행·native 검사·내보내기를 출발점으로 삼는다. 문서·영역 ID, 문서 revision, 구조화된 값·차원·표시 단위·오류와 기능 지원 범위를 안정적인 JSON 계약으로 정리한다.

## 제공할 작업

| 작업 | 범위 |
| --- | --- |
| 문서 조회 | 문서 정보·영역·수식·표·도표와 저장/계산 상태를 조회한다. |
| 문서 수정 | 변수 값·수식·표 셀을 바꾸고 영역을 추가한다. 여러 변경을 한 작업으로 적용한다. |
| 계산 | 명시적으로 재계산하고 결과·단위·오류를 조회한다. 저장된 표시값과 새 계산값을 구분한다. |
| 저장·출력 | 기존 저장 경로와 MCDX·PDF 내보내기를 공통 API에 연결한다. |
| 실행 중 앱 연결 | 로컬 IPC로 열려 있는 문서와 미저장 상태에 접근한다. 파일만 다루는 실행과 세션 연결을 구분한다. |

수정에는 예상 revision을 사용해 오래된 문서 상태에 덮어쓰지 않도록 한다. AI가 적용한 변경도 GUI에 반영하고 Undo/Redo로 복원한다. 편집 초안·Enter 확정·명시 계산의 기존 경계를 보존한다.

## 각 연동의 역할

**CLI**는 일괄 처리와 테스트의 기본 인터페이스다. JSON 출력, 안정적인 종료 코드, 명확한 오류 형식과 버전 계약을 제공한다.

**MCP 서버**는 [공식 Rust SDK rmcp](https://github.com/modelcontextprotocol/rust-sdk)를 사용하고, 처음에는 [로컬 stdio 전송](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)을 제공한다. 로그는 stderr로 보내 프로토콜 출력과 분리한다. 조회는 resources, 실행 명령은 tools로 노출하고 계산 함수를 개별 도구로 무제한 나열하지 않는다. 원격 HTTP 전송은 필요할 때 별도로 설계한다.

**skill**은 [Agent Skills 형식](https://agentskills.io/home)의 `SKILL.md`와 예제로 제공한다. 문서 조회 → 변경 작성 → 계산 → 결과/단위 검증 → 저장의 절차, 지원 범위와 실패 시 대응을 설명한다. 실제 기능은 공통 API·CLI·MCP에서 실행한다.

## 진행 순서와 완료 기준

1. 공통 문서 명령 API와 JSON 계약을 정리한다.
2. 기존 CLI에 조회·수정·계산·저장 흐름을 연결한다.
3. 실행 중 앱과의 IPC 및 revision·Undo 처리를 연결한다.
4. MCP 서버와 연결 예제를 추가한다.
5. skill과 대표 계산서 작성 예제를 제공한다.

같은 문서에 같은 명령을 적용했을 때 GUI·CLI·MCP의 수식·계산 결과·저장 내용이 일치해야 한다. 열려 있는 문서의 수정도 한 작업으로 되돌릴 수 있어야 한다. Windows와 Kubuntu에서 같은 계약을 검증한다.

Obsidian과 VS Code 확장은 기존 방침대로 별도 프로젝트이며, 이 공통 API를 재사용할 수 있다.
