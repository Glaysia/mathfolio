# Prime 12 synthetic reference corpus

`mathcad12.json` contains expressions generated by this project and results from
fresh PTC Mathcad Express Prime 12.0.0.1 calculations. It includes no original
binary, font, schema, product source or user worksheet contents.

Local raw packages and observations remain ignored in
`artifacts/rea/runtime/probes-v2`. Regenerate the normalized corpus without
launching Mathcad:

```sh
python scripts/export-mathcad-reference.py artifacts/rea/runtime/probes-v2 tests/reference/mathcad12.json
cargo run -p mathcraft-cli --locked -- conformance tests/reference/mathcad12.json
```

The exporter verifies package SHA-256, requires Synchronized and settled results,
and joins results through the SAVED worksheet's resultRef. Region IDs and result
IDs can both change during original SaveAs. Presentation fields retain the saved
paper/grid settings needed for load-time placement.

Names identify the intended question, not an assumed answer: `imaginary-square`
and `complex-abs` used an identifier labelled CONSTANT i, which the original
rejected as undefined. `matrix-index-origin1` used VARIABLE ORIGIN, which did not
change SYSTEM ORIGIN. Those negative findings are preserved rather than edited
into expected successful calculations.

Comparison covers displayed scalar/column-vector values, error family, presence
of a previous-error dependency and redefinition flags. Exact diagnostic arguments,
node handles, unit output dimensions, text rendering, editor behavior and complete
product compatibility are outside this corpus. See `docs/CONFORMANCE.md`.
