# Pre-rename document fixture

`pre-rename.mathcraft` is the unchanged synthetic matrix-authoring worksheet
written by the project's Windows integration test on 2026-10-19. It contains
seven saved calculation rows and predates the Mathfolio name. No PTC program,
private worksheet, or third-party source is included.

Origin: `artifacts/rea/area-authoring-integration-20261019/windows/matrix/matrix-authoring.mathcraft`.
The fixture is deliberately kept under its original extension with its original
signature and clipboard/source identities. Regenerating it with the renamed
implementation would remove the independent backward-compatibility check.
